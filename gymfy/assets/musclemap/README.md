## Two constraints this licence puts on Gymfy

Both come from the standard Regular License terms
(<https://codecanyon.net/licenses/terms/regular>), not from an interpretation
of them.

### 1. Gymfy has to stay free to end users

> **Clause 5.** You can make any number of copies of the single End Product,
> as long as the End Product is distributed for Free.
>
> **Clause 7.** You can't Sell the End Product, except to one client.

A Regular License covers a free end product. Charging for the app, adding a
paid tier, or putting any feature behind an in-app purchase requires an
**Extended License** for this item first.

This is not a passing detail — it is a permanent constraint on the business
model, and it is invisible in the code. Nothing in the app will warn you.

### 2. The original pack must not be redistributed

> **Clause 8.** You can't re-distribute the Item as stock, in a tool or
> template, or with source files. This applies whether the Item is
> redistributed freely or for payment, and regardless of any modifications
> made.

So:

- **`assets/musclemap/source/` must never be made public.** It holds the
  pack's unmodified `.svg` files. It is currently tracked in git, which is
  fine *only* because `github.com/Joshynaldo/Gymfy` is a private repository.
  **Making this repository public without removing those files — from the
  history, not just the tip — would put the original item up for free
  download.** See the note at the bottom.
- **The pack must not be bundled into the app.** It isn't: `pubspec.yaml`
  declares `assets/svg/` and `assets/exercises/`, never `assets/musclemap/`.
  `test/muscle_map_licence_test.dart` fails if that ever changes, because
  shipping the raw pack would let an end user extract the item and use it
  separately — clause 11, and the kind of change nobody would think to
  question.

The generated files in `assets/svg/` are a *derivative* — recoloured,
re-tagged per muscle and stripped of the pack's interaction layer. Clause 6
permits modifying the item and using the result in the end product, which is
exactly what they are.

## Attribution

The Regular License does **not** require crediting the author, so there is no
in-app credit for this pack. (Unlike the exercise animations, which are used
with the upstream author's written permission and *are* credited on the Help
screen, and the Schibsted Grotesk typeface, whose OFL licence requires its
text to travel with the font.)

## Regenerating the diagrams

`tool/build_muscle_map.dart` reads
`assets/musclemap/source/with_tooltip_and_colours/*.svg`. If those files are
ever removed from this checkout, re-download the pack from the item URL above
using the original Envato account — the generated SVGs in `assets/svg/` are
committed, so this is only needed to change how they are built.

## If this repository is ever made public

Deleting the files in a new commit is not enough: they stay downloadable from
every earlier commit. The history has to be rewritten and force-pushed —

```
git filter-repo --path gymfy/assets/musclemap/source --invert-paths
```

— which rewrites every commit hash and breaks existing clones. Decide before
flipping the repository to public, not after.
