# Screenshot slots

Drop PNGs or JPEGs here with these exact names and the landing page picks them up. No
code change, no rebuild. Until a file exists, its slot on the page explains
itself rather than showing a broken image.

| Filename | Shows |
|---|---|
| `active-workout.jpg` | The hero. Logging a set mid-workout, weight wheel visible. |
| `overload.jpg` | An exercise with a suggested next weight on screen. |
| `muscle-map.jpg` | The muscle map, shaded by a real week's volume. |
| `themes.jpg` | The theme picker, or a screen on the Hyper theme. |

## Capture notes

- **Aspect ratio 9:19.5** (a normal modern Android screenshot). The frames
  crop with `object-fit: cover`, so anything close works, but a square image
  will lose its top and bottom.
- **Same theme and accent across all four.** Different accents make it look
  like four different apps.
- **Log two or three weeks of data first.** Empty charts are the single most
  common reason a finished site looks unfinished.
- Hyper is the theme worth showing — it is the one thing no competitor's
  screenshots will have.

These are the same shots as the first four in `gymfy/store/screenshots.md`,
so capture once and use both places.
